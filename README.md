# 🔍 DevMatch

## 프로젝트 소개
🤝 DevMatch는 나에게 맞는 팀원을 찾거나, 나를 필요로 하는 팀에 합류할 수 있는 프로젝트 매칭 서비스입니다.<br>
🤖 AI가 지원자의 역량을 분석하여 프로젝트 적합 여부를 판단하고, 팀 내 최적의 역할을 제안하여 모집자의 고민을 덜어줍니다.

## DevMatch의 탄생 배경 ✨

>🤔 프로젝트를 혼자 하긴 부담스럽고, 원하는 역량을 가진 팀원이 있으면 좋겠는데...<br>
>📚 프로젝트에 지원하고 싶은데, 내가 너무 민폐는 아닐까? <br>
>🫂 역량이 겹치는 팀원은 역할을 어떻게 조정하는게 좋을까?

우리는 프로젝트마다 **목표**도 다르고, 보유한 **기술 스택**도 다르고, 가진 **성격**도 다릅니다.<br>
현재 상황에 적합한 동료를 손쉽게 찾고 싶다는 생각, 해보신 적 있지 않나요?<br>
  
저는 이 고민의 답을 `서로를 찾을 수 있는 매개체`에서 찾았습니다.<br>
`함께할 동료의 정보`와 `프로젝트의 방향성`을 알 수 있으면 만족도 높은 만남을 가질 수 있겠다고 생각했어요.

그렇게 동료들과 함께할 수 있는 서비스, `DevMatch`가 탄생하였습니다.
